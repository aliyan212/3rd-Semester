## How to Download (No Git Needed!)

If you just need books, slides, or notes for a quiz or exam:

### 1. Download a Single File (PDF / Doc / Code)
1. Open any subject folder below and click the file you need.
2. Click the **`Download`** button at the top right of the file preview (⤓ icon).
3. The file saves directly to your phone or computer.

### 2. Download Everything (All Subjects at Once)
1. Scroll to the top of this page.
2. Click the green **`<> Code`** button.
3. Click **`Download ZIP`**.
4. Extract the folder on your laptop/phone to have all materials offline.

## Using with Obsidian

All notes are written in Markdown. If you use [Obsidian](https://obsidian.md/):
1. Download or clone this repo to your device.
2. In Obsidian, click **"Open folder as vault"** and select this directory.
3. You'll get instant search, graph view, and interconnected notes automatically.
